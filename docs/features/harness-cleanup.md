# Чистка обвязки: дубли встроенного и повторы текста

## Цель

Убрать из обвязки то, что Claude Code уже делает сам, и привести документацию в соответствие
с актуальными возможностями `settings.json`.

## Область

Входит: `claude/CLAUDE.md` и новые `claude/rules/*.md`, `claude/settings.json`, `SKILL.md`,
reference режима, `README.md`, `install.ps1`, тесты установки.

Не входит: логика Game Master Plan, детектор `bin/project-orchestration.ps1`, awk-проверка
в pre-commit хуке, генератор проектов, шаблоны документов. Поведение обвязки не меняется.

## Критерии готовности

| # | Что должно стать правдой | Чем проверяется |
| --- | --- | --- |
| 1 | Правила разложены по темам в `~/.claude/rules/`, `CLAUDE.md` остаётся коротким ядром | `tests/run-tests.ps1`, проверки `правило rules\<имя> установлено` |
| 2 | Установка не удаляет личные правила пользователя рядом с правилами обвязки | `tests/run-tests.ps1`, проверки `личные правила не удалены` и `сделана копия прежнего правила` |
| 3 | Усилие рассуждения задаётся ключом `effortLevel`, а не только командой в сессии | `tests/run-tests.ps1`, проверка `усилие рассуждения перенесено` |
| 4 | Ключи со значением по умолчанию не тиражируются через обвязку | `tests/run-tests.ps1`, проверка `ключ по умолчанию не тиражируется` |
| 5 | Полные правила определения режима (регистр, ошибки конфигурации, индекс против рабочего дерева) описаны ровно в одном файле, остальные ссылаются на него | `rg PROJECT_ORCHESTRATION_MODE` по репозиторию: в `SKILL.md` и `README.md` правила нет, в `claude/rules/orchestration.md` — только короткий список для маршрутизации |
| 6 | Инструкции, дублирующие встроенное поведение Claude Code, удалены | Ревью diff `claude/CLAUDE.md` и `claude/rules/` |
| 7 | Прежнее поведение установки, генератора и хука не изменилось | `tests/run-tests.ps1` — 90 PASS, 0 FAIL |

## Связь со SPEC

Опирается на границы из `docs/SPEC.md`: deepseting остаётся переносимой обвязкой и не реализует
Master Plan. Решение «явный режим из корневого CLAUDE.md, затем sentinel, затем standard»
не меняется — меняется только место, где оно описано.
