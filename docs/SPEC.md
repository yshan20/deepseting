# Спецификация deepseting

## Назначение

Переносимая обвязка Claude Code: глобальные инженерные правила, project-specifications,
шаблоны, установщик и генератор проектов.

## Границы

Поддерживаются STANDARD_DEEPSETING и совместимость с внешним Game Master Plan.
deepseting не реализует сам Master Plan, не выбирает продуктовый объём и не хранит его состояние отдельно.

## Ключевые решения

| Решение | Причина | Альтернативы |
| --- | --- | --- |
| Явный режим из корневого CLAUDE.md, затем sentinel, затем standard | Детерминизм и приоритет проекта | Эвристики по имени игры отклонены |
| Генератор читает рабочее дерево, hook — индекс | Не менять текущее состояние и проверять фактический коммит | Незастейдженный marker не должен обходить hook |
| Общий PowerShell detector рядом с генератором, самостоятельный sh hook | Установленный hook работает без глобальных зависимостей deepseting | Вызов глобального PowerShell из hook непереносим |

## Ограничения

PowerShell 5.1/7+, Git и shell tools Git for Windows. Runtime не требует сети.
Существующие проектные hooks глобальная установка не мигрирует.
