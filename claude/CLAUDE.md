# Глобальные правила разработки

Эти правила действуют для всех проектов и всех сессий Claude Code.

Явные правила репозитория имеют приоритет над глобальными. В начале работы найди корень
репозитория и прочитай его `CLAUDE.md`, если он есть.

Остальные правила разложены по темам в `~/.claude/rules/` — Claude Code загружает их в начале
каждой сессии наравне с этим файлом:

| Файл | О чём |
| --- | --- |
| `rules/orchestration.md` | Режим проекта: `STANDARD_DEEPSETING` или внешний Game Master Plan. |
| `rules/specifications.md` | Уточняющие вопросы, ведение спецификаций, блокеры и решения без указания. |
| `rules/architecture.md` | Доменная архитектура, границы модулей, обобщаемость, README проекта и подпапок. |

## Формат ответов

- Shell-команды выдавай одной строкой, без переносов через `\` и без обратных кавычек-продолжений — так их можно скопировать целиком.
