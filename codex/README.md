# Payload Codex

`AGENTS.md` содержит только переносимую маршрутизацию, формат ответов и правила игровых ассетов. `skills/project-specifications/` подключается для явных spec/ADR/roadmap/handoff задач, существующего spec-процесса или большой межсессионной координации. В обычных implement/fix/continue/status задачах scaffolding не создаётся.

## Адресные исправления Skills

`skill-patches.json` хранит изменения, полученные при аудите по статье OpenAI «Rethinking skills and prompts for GPT-6 Astra». Они уменьшают лишние активации, повторные approval, ненужный поиск и искусственные viewer/setup требования, сохраняя предметные инструкции навыков.

Патчи:

- не заменяют сторонние Skills целиком и не устанавливают плагины;
- сначала проверяют все найденные цели и прекращают работу до записи при несовпадении версии;
- сохраняют изменяемые файлы рядом как `*.bak-<дата>`;
- не затрагивают `AgentSkillsDir` и Workshop без явных параметров;
- сохраняют поведение повторного запуска без дополнительных изменений.

Unity-патчи привязаны к версии `0.1.6-beta`; после обновления плагина соответствующие записи нужно пересмотреть. Системное обновление может восстановить исходный текст, после чего patches можно проверить и применить повторно.

Команды находятся в [bin/README.md](../bin/README.md). Модель, reasoning effort, sandbox и approval policy audit patches не меняют.
