# Инструкции Codex

`AGENTS.md` задаёт границы автономности и маршрутизацию проекта. Навык
`skills/project-specifications/` хранит рабочий процесс и шаблоны. В режиме
Game Master Plan используются только разрешённые Stage/Wave/Lab документы.

`skill-patches.json` содержит точечные изменения установленных навыков, найденные
при аудите по статье OpenAI «Rethinking skills and prompts for GPT-6 Astra».
Проверка и применение описаны в `../bin/README.md`.

## Что исправлено

- Вопросы только о существенных неизвестных решениях; нет квоты из пяти вопросов.
- Порученная работа не требует повторного утверждения критериев.
- Документы читаются по релевантности; прогресс обновляется по смысловым этапам.
- Архитектурное ревью сообщает о проблемах; реализация не расширяется до чужого рефакторинга.
- Web guidance применяется к новым API, совместимости и неизвестным паттернам.
- Игровые рецепты используются повторно при совпадении условий; новый поиск нужен при изменениях или неопределённости.
- Lottie сохраняет целевой renderer; отдельный viewer и background controls условны.
- Unity Search учитывает уже порученное исправление; UI Toolkit использует доступный Editor для диагностики.
- Поиск Skills применяется к явному запросу или установленному пробелу возможностей.
- OpenAI Docs допускает чтение локальных инструкций и прямое открытие официального URL.

Модель, уровень рассуждений, sandbox и approval policy не изменены этим аудитом.
Патчи не заменяют навыки целиком и не устанавливают плагины. Unity-патчи адресованы
версии `0.1.6-beta`; после обновления плагина нужно пересмотреть соответствующие записи.
Системные обновления также могут восстановить прежний текст. Несовпадение установленной
версии останавливает применение до первой записи; отсутствующие навыки пропускаются.

`AgentSkillsDir` — явно выбранный каталог общих навыков. Его изменение может влиять
на другие агенты, читающие тот же каталог; без параметра этот каталог не затрагивается.
Отдельный `WorkshopDir` обновляет исходник game-creation-patterns, его README и
текст правила в install.py, чтобы новая установка сохраняла выбранный процесс.
Машинные пути мастерской и локальные настройки аккаунта в payload не включены.

Проверки: `powershell -ExecutionPolicy Bypass -File tests/run-tests.ps1` из корня.
